Your PC is ready to pair.

This preview installs the background worker, FFmpeg, ffprobe and a private .NET runtime. Open Optimisarr Sidecar from the Start menu. It lives in the system tray; click the icon for activity and Preferences.

1. Get a pairing code

Open your Optimisarr server, enable Settings → Files & safety → Remote workers, then open Settings → Remote workers and choose Pair a sidecar. Keep its server address and short-lived code ready.

2. Pair this PC

In the tray panel, open Preferences → Pair this PC. Enter the server address and pairing code, approve the administrator request, then choose Start worker. Enable Open tray at sign-in if you want the monitor to open automatically when you sign in.

For headless setup, use an administrator PowerShell window and the folder chosen during installation. The example below uses the default folder and reads the code from standard input.

Set-Location 'C:\Program Files\Optimisarr Sidecar'
.\runtime\dotnet.exe .\Optimisarr.Sidecar.Service.dll --pair https://your-server.example.com

Type the pairing code and press Enter (the console does not print a prompt). Once pairing succeeds:

Start-Service OptimisarrSidecar
Get-Service OptimisarrSidecar

3. Check the worker

The server’s Remote workers settings page shows this PC, its tested encoders and any connection problems. Windows Event Viewer → Windows Logs → Application also records OptimisarrSidecar activity.

The service starts with Windows and works while you are signed out. Temporary work defaults to C:\OptimisarrWork. The original library stays on the server.

Choose where jobs run

On the server, open a library → Choose files → Advanced eligibility → Where this library’s work may run. Only on workers keeps eligible video re-encodes on sidecars. Enable Verify entirely on the sidecar under Settings → Files & safety to require complete worker verification too. Missing evidence then fails the job instead of falling back to container verification. The server still transfers files, evaluates evidence and manages replacement.

The compact monitor

The Precession tray icon opens a rounded activity panel. Processing details, Preferences and Diagnostics stay inside it. Closing the panel keeps the service working; pausing new jobs lets current work finish.

Updates and removal

A newer MSI stops the service before replacing files. Start it again after checking the update. Uninstall through Windows Settings → Apps. Uninstall preserves pairing in C:\ProgramData\Optimisarr\Sidecar and working files; it does not delete media or revoke the worker on your server.

For an existing manually installed service, drain the worker and wait for its current job to finish before migrating to this MSI. Do not install this preview over an active worker.
